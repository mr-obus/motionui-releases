# MotionUI downloads

Installers and update files for [MotionUI](https://motionui.net), the macOS and Windows app that connects Figma, After Effects and AI.

The files live in the release tagged `downloads`. The app updates itself, so there is normally no reason to pick a file here by hand. For a fresh install use the buttons on [motionui.net](https://motionui.net).

This repository holds no source code.
